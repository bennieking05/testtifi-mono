## TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

### If backend errors:
- Check: npm install (ensure all dependencies)
- Check: DATABASE_URL in .env
- Check: JWT_SECRET in .env
- Check: User has admin role in database

### If frontend errors:
- Check: VITE_API_URL points to backend
- Check: User logged in with admin role
- Check: Browser console for API errors
- Check: Network tab for failed requests

### If no data shows:
- Seed some test data in database
- Create test purchases, users, summaries

### If summarize worker stalls:
- Monitor `summaryJob` rows stuck in `status: "processing"`
- Consider adding a safeguard (cron or in-app watchdog) that requeues processing jobs that haven't advanced in N minutes so future restarts don't leave the queue empty
- Wait 5 minutes for cache to refresh

### If downloads missing cover page:
- Check backend console for logo loading messages
- Verify: ls -la backend/og-image.png
- Copy if needed: cp loveable/public/testifi_light_logo.png backend/og-image.png
