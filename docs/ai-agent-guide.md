# AI Agent Guide for Testifi AI Features

## Welcome to Testifi AI!

I'm your AI assistant that helps you navigate and use all features of the Testifi AI platform. Let me guide you through everything available on the site.

## Available Features

### 1. Summary Creation & Management
**What it does:** Upload deposition transcripts and generate AI-powered summaries with page-line citations.

**How to use:**
1. Click **"Create Summary"** from the dashboard
2. Upload a PDF, DOCX, or TXT file
3. Give it a name and optionally enable email notifications
4. Wait ~15-20 minutes for processing
5. View your completed summary with citations

**Questions I can answer:**
- "How do I upload a transcript?"
- "What file formats are supported?"
- "How long does processing take?"
- "How do I download my summary?"

### 2. Admin Dashboard (Admin Only)
**What it does:** Provides analytics, user management, and system configuration tools.

**Available tabs:**
- **Purchase Dashboard**: Revenue and payment analytics
- **Purchase History**: All user transactions
- **User Sign-ups**: New user registrations
- **Download History**: Summary download metrics
- **Support Requests**: Customer support tickets
- **Prompt Playground** (Staging): Edit AI prompts
- **Config Promotion** (Staging): Manage config versions
- **Content Management** (Staging): Edit page content

**Questions I can answer:**
- "How do I view user metrics?"
- "Where are download statistics?"
- "How do I promote config to production?"
- "Can I edit page content?"

### 3. Content Management System (Admin Only, Staging)
**What it does:** Edit any page content without code changes.

**How to use:**
1. Go to Admin Dashboard → Content Management
2. Select a page (e.g., "/help")
3. Click "Edit" to modify content
4. Add/remove sections, change text
5. Click "Save to Staging"
6. Promote to production when ready

**Questions I can answer:**
- "How do I edit the help page?"
- "Can I add new sections?"
- "How do I preview changes?"
- "How do I revert to old content?"

### 4. Config Promotion (Admin Only, Staging)
**What it does:** Manage AI prompt configurations with version control.

**How to use:**
1. Go to Admin Dashboard → Prompt Playground
2. Edit system prompt, temperature, or max tokens
3. Go to Config Promotion tab
4. Click "Save Version" to create snapshot
5. Test the new configuration
6. Click "Promote to Production" when ready

**Questions I can answer:**
- "How do I change the AI prompt?"
- "What's the difference between staging and production?"
- "How do I compare config versions?"
- "Can I revert changes?"

### 5. Download Features
**What it does:** Export summaries in multiple formats (PDF, DOCX, TXT, CSV).

**How to use:**
1. Open a completed summary
2. Click "Download" button
3. Choose format (PDF, DOCX, TXT, or CSV)
4. File downloads with cover page and citations

**Questions I can answer:**

## Step-by-Step Guides

### Creating Your First Summary
1. Login to Testifi AI
2. Click "Create Summary" button
3. Select your transcript file (PDF/DOCX/TXT)
4. Enter a descriptive name
5. Enable email notification (optional)
6. Click "Upload"
7. Wait for processing (15-20 minutes)
8. Receive email when complete
9. Open summary from dashboard
10. Download in desired format

### Promoting Config to Production (Admin)
1. Login as admin
2. Go to Admin Dashboard
3. Click "Prompt Playground" tab
4. Edit prompt configuration
5. Click "Save"
6. Click "Config Promotion" tab
7. Click "Save Version"
8. Test configuration in staging
9. Click "Promote to Production"
10. Confirm promotion
11. Monitor performance metrics

### Editing Page Content (Admin)
1. Login as admin
2. Go to Admin Dashboard
3. Click "Content Management" tab
4. Select page to edit
5. Click "Edit" button
6. Modify sections
7. Add/remove content blocks
8. Click "Save to Staging"
9. Click "Promote to Production"
10. Verify changes on live site

## Tips & Best Practices

### For Users
- Use descriptive names for summaries
- Enable email notifications
- Download completed summaries promptly
- Check your credit balance before uploading
- Use TXT format for fastest processing

### For Admins
- Always test in staging before production
- Create version snapshots before major changes
- Monitor metrics after promotions
- Keep audit trails of changes
- Use preview mode before saving
